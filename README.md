# Lensly AI Content Engine

A Node.js and TypeScript project for automated content collection, AI generation, and publishing.

## Setup

```bash
npm install
npm run dev
```

## Structure

- `src/collectors/` - Content collection modules
- `src/ai/` - AI generation modules
- `src/storage/` - Data storage and persistence
- `src/scheduler/` - Task scheduling and orchestration
- `src/publisher/` - Publishing integrations
- `src/config/` - Configuration management
- `src/types/` - TypeScript type definitions
